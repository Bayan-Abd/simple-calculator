# مشروع الالة الحاسبة البسيطة (Simple Calculator) 
مشروع الة حاسبة تفاعلية و بسيطة تعمل على المتصفح تم بناؤها باستخدام تقنيات الويب الأساسية 
## التقنيات المستخدمة (Technologies)
**HTML5**: لبناء الهيكل الأساسي للالة الحاسبة 
**CSS3**: لتنسيق الألوان و تصميم الأزرار واجهة المستخدم و تحسين مظهرها
**JavaScript**: لاضافة العمليات الحسابية و الوظائف البرمجية (الجمع , الطرح , الحذف , و مسح الشاشة )
## الميزات (Features)
اجراء العمليات الحسابية الأساسية بدقة.
زر الحذف الذكي لاسقاط اخر رقم مدخل (`deletelast`).
زر المسح الشامل لاعادة تعيين الشاشة (`cleardisplay`).
ميزة الحماية من الأخطاء الرياضية (`try...catch`) لمنع تعطل التطبيق.
